# Repository description (≤ 350 chars)
Offline flash card PWA for every grade & subject (Myanmar BE, Cambridge, IB). CSV/Excel/ZIP import, pictures, audio clips, math & chemistry (MathML), tables, 3D models, spaced review, type-the-answer, match game, print & results export. English/Myanmar UI. Vanilla JS, no build, zero network requests.
